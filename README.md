# Rayitos_DE_SOL_Ibarra_ProgramacionGolang
Este es un sistema de gestion para el centro de terapias infantiles Rayitos de sol ubicado en Ibarra, se va a usar programacion orientada a objetos en Golang 
El programa realizado consiste en un sistema de gestión tipo CRUD desarrollado en Golang para el centro de terapias infantiles Rayitos de Sol ubicado en la ciudad de Ibarra. El sistema permite gestionar la información relacionada con estudiantes, representantes y terapeutas, además de permitir llevar un control de diagnósticos, horarios de citas y un sistema contable ligero para conocer la cantidad de clientes registrados. La información actualmente se almacena mediante slices, por lo cual el sistema funciona de manera local y no depende todavía de una base de datos externa. El backend fue desarrollado utilizando diferentes paquetes propios de Golang, entre los cuales se destacan net/http, encoding/json, errors, sort, strconv y sync. Mediante net/http se implementaron los servicios web y las diferentes rutas de la API, mientras que encoding/json permite realizar la serialización de las estructuras utilizadas por el sistema para poder mostrar y transmitir la información mediante JSON. También se implementó un manejo de errores y pruebas unitarias para comprobar que las funciones principales trabajen correctamente y evitar que errores individuales puedan afectar el funcionamiento general del programa.
